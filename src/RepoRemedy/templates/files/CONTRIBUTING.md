## Ways to contribute

We welcome bug reports, bug fixes, documentation improvements and suggestions for
new features. For larger changes, please open an issue first so that maintainers can
discuss the approach with you before you invest time in it.

## Reporting bugs

Do not report security vulnerabilities in public issues. Follow the project's
security policy so that maintainers can prepare a fix before the issue is disclosed.

For other bugs, open an issue that describes what happened, what you expected, the
steps to reproduce the problem and the version you used.

## Suggesting features

Open an issue that describes the problem you want to solve and how you would like
it to work. Maintainers will discuss whether it fits the project.
